Python Number Programs – CRT Training

📌 About the Repository

This repository contains a collection of basic number-based problems implemented in Python as part of my CRT (Campus Recruitment Training) practice.

The programs focus on strengthening fundamental programming concepts, logical thinking, and problem-solving skills.

📝 Programs Covered

The following number-based problems are included:

Palindrome Number – Check whether a number reads the same forward and backward.

Reverse a Number – Reverse the digits of a given number.

Leap Year – Check whether a given year is a leap year.

Factorial – Calculate the factorial of a given number.

Armstrong Number – Check whether a number is an Armstrong number.

Perfect Number – Check whether a number is equal to the sum of its proper divisors.

Count Digits – Count the total number of digits in a given number.

🛠️ Technologies Used

Programming Language: Python

Concepts: Conditional Statements, Loops, Arithmetic Operators, and Basic Functions.

🎯 Learning Objectives

Improve logical and analytical thinking.

Understand basic number manipulation techniques.

Strengthen Python programming fundamentals.

Develop problem-solving skills for coding assessments and placement preparation.
